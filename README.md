# Node.js project - Group Buying

מערכת Web מתקדמת לניהול וריכוז רכישות קבוצתיות, המאפשרת התאגדות צרכנים חכמה ויצירת מכרזים סגורים לספקים בזמן אמת.

---

## תכונות מרכזיות במערכת

* **ניהול משתמשים כפול:** מערכת הרשמה והתחברות מאובטחת המבדילה בין לקוחות לספקים עם הרשאות מותאמות.
* **מנגנון רכישה קבוצתית:** אפשרות ליצירת קבוצות רכישה חדשות, הצטרפות לקבוצות קיימות ועדכון דינמי של מצבת החברים.
* **מערכת מכרזים חיה:** ספקים יכולים להגיש הצעות מחיר לקבוצות פתוחות, כאשר המערכת מחשבת ומציגה אוטומטית את ההצעה המשתלמת ביותר.
* **אבטחה ואימות:** שימוש ב-JWT לניהול Sessions וב-Bcrypt להצפנה חזקה של נתוני המשתמשים.
* **ממשק ניהול יוצר:** בעל הקבוצה יכול לעדכן את פרטי המוצר או לסגור את הקבוצה למבצעים חדשים.

---

## טכנולוגיות וכלים

* **Node.js:** סביבת הריצה המרכזית של השרת.
* **Express.js:** מסגרת פיתוח לניהול נתיבים (Routing) ותהליכי ביניים (Middleware).
* **MongoDB & Mongoose:** ניהול בסיס הנתונים בתצורת NoSQL עם סכמות קפדניות לנתונים.
* **EJS Templates:** מנוע תצוגה ליצירת ממשק משתמש בצד השרת.
* **JWT & Cookie-Parser:** ניהול אבטחה והעברת נתוני זיהוי בין הלקוח לשרת.

---

## מבנה הפרויקט (Architecture)

המערכת בנויה במבנה **MVC** מסודר להפרדה מלאה בין הלוגיקה לתצוגה:
* **Models:** ניהול המידע והקשרים מול מסד הנתונים.
* **Controllers:** הלוגיקה העסקית המקשרת בין הנתונים לבקשות המשתמש.
* **Routes:** ניתוב הבקשות מהדפדפן לפונקציות המתאימות.
* **Views:** דפי ה-HTML המוצגים למשתמש הקצה.
